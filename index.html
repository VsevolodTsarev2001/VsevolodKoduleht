Selgitused: Kuidas luua ja hallata kaug-repositooriumit

Git on hajutatud versioonihaldussüsteem, mida kasutatakse koodiprojektide haldamiseks. Kaug-repositooriumi (nt GitHub, GitLab) abil saab hoida projekti versioone ja jagada seda teiste arendajatega. Siin on sammud, kuidas luua kaug-repositoorium ja seostada see kohaliku repoga.

1. Loo kaug-repositoorium

Esimene samm on luua kaug-repositoorium GitHubis või mõnes muus teenuses, nagu GitLab või Bitbucket. Kui olete repo loonud, saadate selle URL-i, mida kasutatakse kaug-repositooriumiga ühendamiseks.

2. Seosta oma kohalik repo kaug-repositooriumiga

Kui teil on kohalik projekt, mille olete juba Gitiga versioonihaldusesse viinud, siis saate selle ühendada kaug-repositooriumiga käsuga:

git remote add origin https://github.com/teie_kasutajanimi/teie_repo.git

Kus origin on kaug-repositooriumi nimi ja https://github.com/teie_kasutajanimi/teie_repo.git on kaug-repositooriumi URL, mille saate GitHubist.

3. Failide lisamine ja commitimine

Kui olete oma failid valmis saanud, tuleb need lisada versioonihaldusse ja teha esimene commit:

git add .
git commit -m "Esimene commit: Minu portfolio"

Esimene käsk git add . lisab kõik failid, teiseks käsk git commit -m "Esimene commit" teeb commit'i, ehk salvestab muudatused.

4. Pushimine kaug-repositooriumisse

Kui failid on commititud, saate need saata kaug-repositooriumisse järgmise käsuga:

git push -u origin master

Kui kasutate muud haru, näiteks main, siis kasutage seda:

git push -u origin main

5. Tõmbamine kaug-repositooriumist (Pull)

Kui teised arendajad on teinud muudatusi või olete töötanud mitmesugustes keskkondades, saate värskendada oma kohalikke faile järgmise käsuga:

git pull origin master

Kui kasutate main haru, siis muutke käsu lõppu vastavalt:

git pull origin main

Kokkuvõte

Kaug-repositooriumi kasutamine Gitiga võimaldab teil hoida oma projektide ajalugu ja jagada seda teistega. Ühendage oma kohalik repo kaug-repositooriumiga, tehke muudatusi, commitige need ja pushige kaug-repositooriumisse. Samuti saate igal ajal võtta kõige värskema versiooni projekti muudatustest.
